# data/ — video-uri și adnotări de test

Aici stau materialele locale pentru demo. Clipurile și adnotările nu intră în git; doar README-urile cu sursă și licență rămân versionate.

- `videos/` — câte un clip verificat pentru fiecare caz din demo.
- `annotations/` — etichete în format YOLO pentru clasele ad-hoc.

Pentru fiecare material, notați sursa, licența, cine l-a filmat sau adnotat și data. Fără acord scris, materialul nu se publică.
