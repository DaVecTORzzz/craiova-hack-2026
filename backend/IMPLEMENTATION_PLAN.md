| Package manager | `uv` (`backend/pyproject.toml`) |

| Report text | Produced by Dalina's module `automation.report` (role D), called in process. If it is missing, slow (> 3 s) or fails, the backend uses its own template. |
| Python package name | `app` (inside `backend/`) |

## 4. Time helpers — `app/timeutil.py` (VERBATIM)

```python
from datetime import datetime, timezone
from zoneinfo import ZoneInfo

LOCAL_TZ = ZoneInfo("Europe/Bucharest")


def utcnow() -> datetime:
    """Naive UTC 'now', the only form stored in the DB."""
    return datetime.now(timezone.utc).replace(tzinfo=None)


def to_naive_utc(dt: datetime) -> datetime:
    if dt.tzinfo is None:
        return dt
    return dt.astimezone(timezone.utc).replace(tzinfo=None)


def iso(dt: datetime | None) -> str | None:
    """Naive UTC -> '2026-10-30T10:42:13.120Z'."""
    if dt is None:
        return None
    return dt.replace(tzinfo=timezone.utc).isoformat(timespec="milliseconds").replace("+00:00", "Z")


def local_hms(dt: datetime) -> str:
    """Naive UTC -> '10:42:13' in Europe/Bucharest."""
    return dt.replace(tzinfo=timezone.utc).astimezone(LOCAL_TZ).strftime("%H:%M:%S")
```

## 7. Behaviour rules (the hard decisions, already made)

### 7.1 Ingestion of `POST /edge/events`

1. Check `X-Edge-Token`. Missing or wrong → **401** `{"detail": "invalid edge token"}`.
2. Validate the body with `EdgeEventIn`. Any error, including extra fields like `status` → **422** (FastAPI does this automatically).
3. If `camera_id` is not in `cameras` → **404** `{"detail": "unknown camera_id"}`. If `zone_id` is not in `zones` **and** `type != CAMERA_OFFLINE` → **404** `{"detail": "unknown zone_id"}`. For `CAMERA_OFFLINE`, any `zone_id` is accepted.
4. If an event with the same `event_id` exists → **200** with the existing `EventOut`. Nothing else happens: no broadcast, no Slack, no new timer.
5. Otherwise insert it with `status="open"`, `received_at=utcnow()`, `detected_at` converted to naive UTC, then:
   1. update the camera: `online=False` if `type == CAMERA_OFFLINE`, else `online=True`;
   2. commit;
   3. broadcast `event.created` with the full `EventOut`;
   4. `asyncio.create_task(notify_new_event(event_id))` (step 9);
   5. `asyncio.create_task(generate_and_store_report(event_id))` (step 10);
   6. `schedule_escalation(event_id)` (step 8);
   7. return **201** with the `EventOut`.
6. Log one line: `ingest event_id=... type=... ingest_latency_ms=<received_at - detected_at>`.

The response must be sent without waiting for Slack or the report. Steps 5.4 to 5.6 only start background work.

### 7.2 Serialization

One function, `event_out(session, event: Event) -> EventOut`, used by every route and by the WebSocket. It rebuilds `confidence` from the three columns, formats all datetimes with `iso()`, and loads `report` from `report_texts` (or `None`). Never build `EventOut` anywhere else.

### 7.3 Operator actions and the status machine

Body for all three: `OperatorActionIn` (`operator` required, `note` optional).

| Action | Allowed from | New status | Field changes | Timer | Action row |
|---|---|---|---|---|---|
| `POST /events/{id}/ack` | `open`, `escalated` | `acknowledged` | `acked_at=now`, `acked_by=operator` | cancel | `ack` |
| `POST /events/{id}/false-positive` | `open`, `escalated`, `acknowledged` | `false_positive` | none | cancel | `false_positive` (with `note`) |
| `POST /events/{id}/reopen` | `acknowledged`, `false_positive`, `escalated`, `resolved` | `open` | `acked_at=None`, `acked_by=None`, `escalated_at=None` | restart from now | `reopen` |

- Unknown `event_id` → **404**. Status not in "Allowed from" → **409** `{"detail": "cannot <action> an event with status <status>"}`.
- After a successful action: commit, broadcast `event.updated`, return **200** with `EventOut`.
- `resolved` is never set by the backend in the demo. It exists only in the enum.

### 7.4 Escalation — `app/services/escalation.py`

- Keep `_timers: dict[str, asyncio.Task]` in the module.
- `schedule_escalation(event_id, delay_s=None)`: read the event's zone. If the zone has `escalate_after_s is None`, or the event is `CAMERA_OFFLINE`, do nothing. Otherwise cancel any existing timer for that event and start a task that sleeps `delay_s` (default: the zone's `escalate_after_s`) and then calls `escalate(event_id)`.
- `cancel_escalation(event_id)`: cancel and remove the task if present.
- `escalate(event_id)`: open a new session, reload the event. **Only if its status is still `open`**: set `status="escalated"`, `escalated_at=now`, add an action row (`escalate`, operator `"system"`), commit, broadcast `event.updated`, and send the Slack escalation message (`escalated=True`). Otherwise do nothing.
- `recover_timers()` runs at startup: for every event with status `open` whose zone has `escalate_after_s`, compute `remaining = received_at + escalate_after_s - now`. If `remaining <= 0`, call `escalate()` now, else schedule with `delay_s=remaining`.

### 7.5 Slack — `app/services/notify.py`

- `async def send_slack(text: str) -> bool`: if `slack_webhook_url` is empty, log `notification simulated: <text>` and return `False`. Otherwise `POST` JSON `{"text": text}` with `httpx.AsyncClient(timeout=3)`; return `True` on 2xx, else log the status code and return `False`. Never raise.
- `def slack_text(event: EventOut, escalated: bool) -> str`: if `automation.report` exists and has a function `slack_text(event: dict, escalated: bool) -> str`, use it inside `try`; on any error, or if it is missing, use the default template:
  - normal: `[{severity}] {type} · {camera_id} / {zone_id} · {HH:MM:SS local} · {app_base_url}/incidents/{event_id}`
  - escalated: `ESCALADARE · neconfirmat de {escalate_after_s} s · ` + the normal text
- `notify_new_event(event_id)`: build the text from the current `EventOut`, send it, and if `True`: set `notified_at=now`, commit, broadcast `event.updated`. If `False`, leave `notified_at` null. The UI shows that as "notificare neconfirmată"; the backend must not pretend it was sent.

### 7.7 Cameras, zones and `config_version`

- `GET /cameras` → list of `CameraOut`, ordered by id.
- `PUT /cameras/{camera_id}/engine` with `EngineIn` → 404 if unknown; set `engine_on`, `updated_at=now`, increment `config_version`; return `CameraOut`.
- `GET /zones?camera_id=` → list of `ZoneIO` (all zones if `camera_id` is missing), ordered by id.
- `PUT /zones/{zone_id}` with `ZoneIO` → 422 if `body.id != zone_id`; 404 if `body.camera_id` is unknown; insert or replace the zone; increment `config_version`; return `ZoneIO`.
- `POST /zones/reference-frame` (multipart: `zone_id` form field + `file`) → 404 if the zone is unknown; 415 if not `image/jpeg`; 413 if larger than 5 MB; save to `{snapshot_dir}/reference/{zone_id}.jpg`; set `zone.reference_frame="/snapshots/reference/{zone_id}.jpg"`; increment `config_version`; return `ZoneIO`.
- `GET /edge/zones?camera_id=` (edge token required) → `EdgeZonesOut` for that camera; 404 if unknown camera.

### 7.8 Snapshots

- `POST /edge/snapshots` (edge token; multipart: `file`, optional form field `event_id`). 415 if the content type is not `image/jpeg`; 413 if larger than 5 MB. File name: `{event_id}.jpg` when `event_id` matches `EVENT_ID_PATTERN`, otherwise `snap_{uuid4().hex}.jpg`. Save into `snapshot_dir`, insert a `snapshots` row with `expires_at = now + retention_days`, return **201** `{"snapshot_url": "{snapshot_base_url}/snapshots/{file_name}"}`.
- Serve the folder with `app.mount("/snapshots", StaticFiles(directory=snapshot_dir), name="snapshots")`. Create the folder (and `reference/`, `live/`) at startup if missing.
- Automatic deletion after `retention_days` is roadmap. Do not implement it.

### 7.9 WebSocket — `app/ws.py` and `app/routers/ws.py`

- `ConnectionManager` with `connect(ws)`, `disconnect(ws)`, `async broadcast(type: str, data: dict)`. Broadcast sends `{"type": type, "data": data}` as JSON to every client; a client that raises on send is removed. One global instance.
- Route `/ws/events`: accept, register, then loop on `await ws.receive_text()` (ignore the content; it only keeps the socket alive). On `WebSocketDisconnect`, unregister.
- `type` is only ever `"event.created"` or `"event.updated"`. `data` is always `EventOut.model_dump(mode="json")`.

### 7.10 KPI and shift report — `app/services/kpi.py`

- Shifts in local time (`Europe/Bucharest`): `morning` 06:00–14:00, `afternoon` 14:00–22:00, `night` 22:00–06:00 (ends the next day). Convert the window to naive UTC before querying `detected_at`.
- `GET /kpi?date=YYYY-MM-DD&shift=morning`. If both are missing, use the shift that contains "now". If only one is missing → 422.
  - `open_incidents`: events in the window with status `open` or `escalated`.
  - `escalated`: events in the window with `escalated_at` not null.
  - `avg_detection_to_alert_s`: mean of `notified_at - detected_at` in seconds over events in the window with `notified_at`, rounded to 1 decimal; `null` if none.
  - `ppe_compliance`: `1 - valid_no_ppe / ppe_observations_per_shift`, clamped to [0, 1], rounded to 2 decimals, where `valid_no_ppe` = `NO_PPE` events in the window whose status is not `false_positive`. See OPEN QUESTION Q3.
- `GET /reports?shift=&date=` (both required) → `ShiftReport` with the KPI above and:
  - `by_type`: one item per type present: `{"type", "critical", "warning"}` counts.
  - `by_zone`: one item per zone present: `{"zone_id", "critical", "warning", "avg_ack_s"}`; `avg_ack_s` = mean of `acked_at - detected_at` in whole seconds, `null` if none acked.
  - `by_hour`: `{"hour": "HH", "count"}` by local hour, only hours with events, sorted.
  - `summary`: `automation.report.summarize(report_dict_without_summary)` in `try` with a 3 s timeout; fallback: `Tura {shift} din {date}: {n} evenimente, {open_incidents} deschise, {escalated} escaladate.`

### 7.11 Health — `GET /health`

Return `{"status": "ok" | "degraded", "db": bool, "edge_last_seen_s": float | null, "mock": bool}`. `db` = a `SELECT 1` succeeds. `edge_last_seen_s` = seconds since the last authorized `/edge/*` request (kept in memory), `null` if never. HTTP 200 when `db` is true (status `degraded` if `edge_last_seen_s` is null or > 60 and mock is off), **503** when `db` is false.

### 7.12 Errors

Use FastAPI's default `{"detail": ...}` body for all errors. Do not invent another error format.
